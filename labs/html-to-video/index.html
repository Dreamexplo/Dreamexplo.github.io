说明与已知限制
页面在你本地浏览器中渲染与录制（Canvas captureStream / html2canvas 逐帧 + ffmpeg.wasm 转码），文件不离开你的设备。上传 ZIP 时通过 Service Worker 提供同源虚拟目录，保证相对资源与 canvas 录制可用。
自动 / 逐帧模式：按帧推进 CSS / WAAPI / rAF 动画并烘焙状态，动效可完整保留；canvas、WebGL、video 这类实时像素源会在截图后按原位补绘，不再出现“整页正常、动画区一块黑”。
演示录制模式：适用于游戏、可点击 Demo、需要键盘鼠标操作或真实时钟的页面。工具会新开标签页并在授权后采集该标签页画面，点“进入全屏”后无地址栏播放，全程真实录下；结束后回到本页点“停止”。
授权时选什么：弹窗里选“这个标签页 / Chrome 标签页”，录到的是纯网页画面；误选“整个屏幕/窗口”时状态栏会明确提醒。
解说音频：勾选“录解说”后，麦克风解说与画面同轨录制，不需要后期对轨；也可导入现成配音，与原声、背景音乐按各自音量混合。
时长为什么准了：逐帧模式按“帧号 ÷ 帧率”推进时间轴，末尾统一按设定时长截断；实时模式按目标时刻排帧，不会因渲染慢而漂移。
已知限制：逐帧模式下 html2canvas 不支持 backdrop-filter、iframe 内内容与 Shadow DOM；演示模式为标签页/屏幕级采集，会如实录下鼠标光标与浏览器界面。
