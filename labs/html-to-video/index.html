说明：页面在你本地浏览器中渲染与录制（Canvas captureStream / html2canvas 逐帧 + ffmpeg.wasm 转码），文件不离开你的设备。ZIP 上传通过 Service Worker 提供同源虚拟目录，保证相对资源与 canvas 录制可用。
自动 / 逐帧模式：按帧推进 CSS / WAAPI / rAF 动画并烘焙状态，动效可完整保留；canvas、WebGL、video 这类实时像素源会在截图后按原位补绘，不再出现“整页正常、动画区一块黑”。
演示录制模式：适用于游戏、可点击 Demo、需要键盘鼠标操作或真实时钟的页面。工具会新开一个标签页并在你授权后采集该标签页画面；新标签页里会先出现一个“进入全屏”按钮，点它即可在没有地址栏 / 任务栏的状态下播放、点击、游玩，全程真实录下来，结束后回到本页点“停止”成片。
授权时选什么：弹窗里请选“这个标签页 / Chrome 标签页”，这样录到的是纯网页画面（天然全屏、无地址栏）；误选“整个屏幕”或“窗口”时工具会在状态栏明确提醒，成片会带桌面或标题栏。
页面有“点击开始”遮罩：自动模式下工具会识别铺满画面的开始遮罩，并自动把它的选择器填进「播放启动动作」，录制前先点它；若点了没反应，直接用演示录制自己点开后录。
已知限制：逐帧模式下 html2canvas 不支持 backdrop-filter、iframe 内内容与 Shadow DOM；演示模式为标签页/屏幕级采集，会如实录下鼠标光标与浏览器界面（若选择整个屏幕）。
